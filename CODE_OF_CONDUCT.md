# Code Of Conduct

Simphony contributors are expected to keep project discussions professional, focused, and respectful.

## Expected Behavior

- Use welcoming and inclusive language.
- Be respectful of different experience levels and viewpoints.
- Keep feedback specific, constructive, and tied to the work.
- Accept maintainer decisions about project scope, security posture, and release timing.
- Avoid sharing private credentials, sensitive logs, private repository details, or confidential issue content in public spaces.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Sexualized language or imagery.
- Publishing another person's private information without permission.
- Repeated disruption of issues, pull requests, reviews, or discussions after a maintainer asks for a change in behavior.
- Using project spaces to solicit credentials, access tokens, or private operational details.

## Reporting

Report conduct concerns to the maintainers through the project's preferred private channel. If no private channel is available, open a minimal public issue asking for a private contact path and do not include sensitive details.

Maintainers may remove comments, close discussions, block accounts, or take other reasonable steps to keep the project usable and safe for contributors.
